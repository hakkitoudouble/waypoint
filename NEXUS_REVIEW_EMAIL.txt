What the mod is
---------------
Waypoint is a read-only companion for theHunter: Call of the Wild. It starts a small
local web server on 127.0.0.1:8765 and opens the interface in the user's browser. It
parses the game's save files (opened read-only, never written) to list the reserve's
population and its discovered need zones, and it reads the positions of the animals
currently simulated around the player out of the game's process memory.

Technical details that matter for your review:
  - No file is installed into the game folder, nothing is patched, no mod is injected.
  - The save scanner is strictly read-only.
  - The live layer uses ReadProcessMemory on the game's own process from a separate
    user-mode program: no DLL injection, no hooks, no driver, no network.
  - The program talks to nothing but 127.0.0.1 (its own local server).
  - State written by the app itself lives in %LOCALAPPDATA%\Waypoint.

Why the archive contains an executable
--------------------------------------
The application is written in Python and packaged with PyInstaller (one-folder build),
which is why the archive contains Waypoint.exe plus a visible `_internal` folder of
Python runtime files and PNG/JSON assets. PyInstaller binaries are a well-known source
of heuristic and VirusTotal false positives; the archive is not packed, obfuscated or
nested. "Preview file contents" shows the whole tree.

Source code and build steps
---------------------------
Public repository (MIT, code only - the game-derived assets are credited separately):
  https://github.com/hakkitoudouble/waypoint

Build from source, on Windows, with Python 3.12:
  1. pip install pyinstaller numpy
  2. git clone https://github.com/hakkitoudouble/waypoint
  3. cd waypoint
  4. python build.py
  -> produces dist/Waypoint/Waypoint.exe and dist/Waypoint-1.0.0-win64.zip

The uploaded binary was produced by the public GitHub Actions pipeline, and the same
archive is attached to the GitHub release, so it can be compared byte for byte:

  release : https://github.com/hakkitoudouble/waypoint/releases/download/v1.0.0/Waypoint-1.0.0-win64.zip
